# Landing-Page-AfroPatos
Landing page da Afros Patos, studio de tranças afro em Patos de Minas (MG). Projeto de UI/UX com Início, Modelos de Tranças, Agendamento direto no WhatsApp, Dúvidas Frequentes, Sobre Mim e Localização. Identidade visual terrosa com formas orgânicas, pensada para conversão e para o celular. HTML, CSS e JavaScript.
